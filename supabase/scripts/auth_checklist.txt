Checklist P1 — Supabase Auth (configurar no painel)
====================================================

[ ] Site URL = URL de produção (ex.: valor de NEXT_PUBLIC_APP_URL)
[ ] Redirect URLs explícitas (ex.: https://app/auth/callback, http://localhost:3000/auth/callback)
[ ] Sem wildcards (*) em produção
[ ] JWT expiry = 3600 segundos (1 hora) ou conforme política interna
[ ] Password strength / leaked password protection ativados
[ ] Confirm email habilitado se registo público estiver ativo
[ ] Backup automático ativo + teste de restauração documentado

Data API (P2 — Settings → API)
[ ] Expor apenas schema public (ou desativar Data API se 100% via Next.js)
[ ] GraphQL desativado se não utilizado
